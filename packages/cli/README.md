# 🚀 @dark-matter/cli

> The complete Dark Matter umbrella suite for **Google Antigravity (`agy`)**.

Installs and configures the entire Dark Matter suite in a single command:
* **`@dark-matter/neuron`**: Long-term persistent cognitive memory engine
* **`@dark-matter/statusline`**: Modular, telemetry-aware live status bar
* **`@dark-matter/milestone`**: Decoupled terminal task and milestone execution tracker

---

## Installation

```bash
agy install @dark-matter/cli
# or via npx
npx @dark-matter/cli install
```

See the [main repository README](../../README.md) for full ecosystem details.
